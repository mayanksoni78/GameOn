# Game On 🎮

A collection of classic mini-games (2048, Blockodoku, Tetris, Snake, Bingo, Connect 4, Sudoku, Tic-Tac-Toe, Dino Jump, Flappy Bird, and more) bundled into a single Expo / React Native app.

## Tech stack

- **Expo** (SDK 54) + **Expo Router** for file-based routing
- **React Native** 0.81 / **React** 19
- **React Navigation** (native stack) for in-app game navigation
- **react-native-gesture-handler** + **react-native-reanimated** for drag/swipe interactions
- **AsyncStorage** for local high-score persistence
- **NativeWind** / Tailwind for styling utilities
- **expo-haptics**, **expo-blur** for UI polish

**How navigation ties together:** `app/index.tsx` renders `navigation/index.js`, which is a React Navigation native-stack navigator. Each entry in that stack maps a route name (e.g. `"Tetris"`) to a screen component in `screens/`. To add a new game, create a screen file and register it there.

## Prerequisites

- **Node.js** 18+ (LTS recommended)
- **npm** (project uses `package-lock.json`)
- No global Expo CLI install needed — `npx` handles it

## Getting started

```bash
# 1. Move into the project root (the folder containing package.json)
cd GameOn-main

# 2. Install dependencies
npm install

# 3. Start the Expo dev server
npx expo start
```

This opens an interactive terminal menu. From there:

| Key / Command | What it does |
|---|---|
| `w` | Open in your browser |
| `a` | Open in an Android emulator (requires Android Studio setup) |
| `i` | Open in an iOS simulator (macOS only) |
| Scan the QR code | Open on your phone via the **Expo Go** app |

Or run a platform directly:

```bash
npm run web       # expo start --web
npm run android   # expo run:android
npm run ios       # expo run:ios
```

### Useful flags

- `npx expo start -c` — clear the Metro bundler cache (helpful after changing native config like `app/_layout.tsx`, or after installing a new native module)
- `npx expo start --tunnel` — use when your phone and dev machine aren't on the same network

## Notes

- `firebase` is listed as a dependency but isn't currently wired into any screen — no Firebase setup/config is required to run the app.
- `backend/server.java` is an empty stub, unrelated to running the app.
- `chess.js` and `PacmanGame.js` exist as screens but aren't yet registered in `navigation/index.js`.
